# 🎓 NightCoder Student Management System

A beginner-friendly **PHP CLI project** that collects student information and processes it using conditional statements and loops.

## 🚀 Features

* 📝 Accepts student name, age, ID number, and marks.
* 🔢 Converts numeric inputs into integers.
* 🧑 Classifies students by age:

  * Adult
  * Teenager
  * Child
* 🔐 Demonstrates basic conditional access logic using age and ID.
* 📊 Evaluates marks and displays a performance category.
